7. Redes de flujo

  • Red de flujo: grafo dirigido con capacidades ce ≥ 0, un único nodo fuente s y un único sumidero t.
  • Flujo s-t: f: E → ℝ⁺ con (1) 0 ≤ f(e) ≤ ce para toda arista y (2) en todo nodo interno, flujo entrante = flujo saliente.
  • Grafo residual Gf: mismos nodos. Por cada e = (u, v): si f(e) < ce, arista forward (u, v) con capacidad ce − f(e); si f(e) > 0, arista backward (v, u) con capacidad f(e).
  • Cuello de botella de un camino s-t: mínima capacidad residual de sus aristas.

Ford-Fulkerson

f(e) = 0 para toda e
while exista camino simple P s-t en G_f:
    b = cuello de botella de P
    forward:  f(e) += b        backward: f(e') -= b
    actualizar G_f

Tiempo O(mC), con C la suma de las capacidades de las aristas que salen de s (cota para el valor del flujo).

Flujo máximo = corte mínimo

  • Para todo corte (A, B) s-t: v(f) = fout(A) − fin(A).
  • Para todo corte: v(f) ≤ c(A, B).
  • Por lo tanto, el valor máximo de un flujo s-t es igual a la mínima capacidad de un corte s-t.

Pseudocódigo: Aumentar

Aumentar(f, P):
  b = cuello de botella de P en G_f
  para cada arista e = (u, v) de P:
      si e es forward:   f(e) = f(e) + b
      sino (backward, e' = (v, u)):  f(e') = f(e') − b
  devolver f

Pseudocódigo: Ford-Fulkerson completo

Flujo-Maximo(G, s, t):
  f(e) = 0 para toda arista e
  mientras exista un camino simple P de s a t en G_f:
      f = Aumentar(f, P)
      actualizar G_f
  devolver f

Cómo obtener el corte mínimo al terminar: sea A el conjunto de nodos alcanzables desde s en Gf (con BFS) y B = V − A. Ese (A, B) es un corte de capacidad mínima y su capacidad es igual al valor del flujo. Este paso no está en el resumen.
