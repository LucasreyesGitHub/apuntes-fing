5. Divide y vencerás

Dividir en subproblemas, resolverlos de forma independiente y combinar las soluciones. El tiempo queda expresado como una recurrencia.

Resolver recurrencias

  • Desenrollar: expandir los primeros niveles, encontrar el patrón en la cantidad y tamaño de subproblemas, sumar sobre todos los niveles.
  • Sustituir: proponer una cota (ej. c·log₂ n) y verificar que cumple la recurrencia.
  • Sustitución parcial: usar parámetros genéricos y despejar qué valores deben tener.

MergeSort

T(n) ≤ 2T(n/2) + cn, T(2) ≤ c. En el nivel j hay 2j subproblemas de tamaño n/2j, que suman cn por nivel. Con log n niveles: T(n) = O(n log n).

Ordeno(L): si |L| ≤ 1 devolver L
           L1 = Ordeno(primera mitad); L2 = Ordeno(segunda mitad)
           devolver Combino(L1, L2)       // merge lineal con dos punteros

Conteo de inversiones

Mide cuán distintas son dos listas de preferencias. Hay una inversión si i < j pero en la otra lista aj aparece antes que ai. Se cuenta mientras se ordena: al combinar A y B ordenadas, cada vez que se elige un elemento de B, se suman las inversiones con todos los elementos que quedan en A.

Ordeno&Cuento(L): si |L| = 1 devolver 0
    (iA) = Ordeno&Cuento(A); (iB) = Ordeno&Cuento(B)
    iAB = Une&Cuento(A, B)             // suma |restantes de A| cada vez que sale un b
    devolver iA + iB + iAB

Tiempo: O(n log n), igual que MergeSort.

Pseudocódigo: Combino (merge)

Combino(L1, L2):
  i = 0;  j = 0;  Res = []
  mientras i < |L1| y j < |L2|:
      si L1[i] ≤ L2[j]: Res.agregar(L1[i]);  i++
      sino:             Res.agregar(L2[j]);  j++
  agregar a Res lo que quede de L1 y de L2
  devolver Res

Si no se agrega el resto al salir del bucle, se pierden elementos.

Pseudocódigo: Une&Cuento

Une&Cuento(A, B):                         // A y B ya ordenadas
  i = 0;  j = 0;  inv = 0;  Res = []
  mientras i < |A| y j < |B|:
      si A[i] ≤ B[j]: Res.agregar(A[i]);  i++
      sino:           Res.agregar(B[j]);  inv += |A| − i;  j++   // B[j] es menor que todo lo que queda en A
  agregar los restos de A y B
  devolver (Res, inv)
