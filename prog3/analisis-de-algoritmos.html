2. Análisis de algoritmos

Las notaciones son insensibles a constantes y a términos de menor orden.

NotaciónDefiniciónSignifica
T(n) = O(f(n))∃ c > 0, n₀: ∀ n ≥ n₀, T(n) ≤ c·f(n)Cota superior
T(n) = Ω(g(n))∃ c > 0, n₀: ∀ n ≥ n₀, T(n) ≥ c·g(n)Cota inferior
T(n) = Θ(f(n))O(f) y Ω(f)Crece exactamente como f
T(n) = o(f(n))límn→∞ T(n)/f(n) = 0Cota superior estricta

Propiedades

  • O, Ω y Θ son transitivas.
  • Si f = O(h) y g = O(h), entonces f + g = O(h).
  • logb n = O(nx) para todo b > 1, x > 0. La base del logaritmo no importa (cambia por una constante).
  • nd = O(rn) para todo r > 1, d > 0: toda exponencial le gana a un polinomio.
El tiempo de un algoritmo depende de las estructuras de datos elegidas. Revisá siempre qué costo tiene cada operación.
