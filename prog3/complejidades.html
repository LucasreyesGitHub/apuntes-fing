Cómo justificar la cota de cada algoritmo

AlgoritmoCotaJustificación que piden los correctores
Gale-ShapleyO(n²)Cada iteración hace una propuesta nueva y hay n² posibles. Con Ranking, Next y Current cada iteración es O(1).
BFS / DFSO(n + m)Cada nodo entra una sola vez a la cola/pila (marcado antes de entrar) y cada arista se mira desde sus dos extremos: n + 2m.
Orden topológicoO(n + m)Cada nodo entra una vez a L y cada arista descuenta un grado una sola vez.
Dijkstra / PrimO(m log n)n ExtractMin y a lo sumo m ChangeKey, cada uno O(log n).
KruskalO(m log n)Ordenar m aristas cuesta O(m log m) = O(m log n), porque m ≤ n².
Intervalos ponderadosO(n log n)Ordenar O(n log n); p(j) por búsqueda binaria O(n log n); la tabla son n celdas O(1).
MochilaO(nW)(n+1)(W+1) celdas con trabajo O(1) cada una. Pseudo-polinomial.
Mínimos cuadrados segmentadosO(n³)n² pares (i, j) y O(n) para cada error ei,j; el llenado de OPT es O(n²).
ARNO(n³)O(n²) subproblemas {i..j} y O(n) valores de t para cada uno.
AlineaciónO(mn)Tabla de m × n con O(1) por celda.
Ford-FulkersonO(mC)C es la capacidad de cualquier corte y acota las iteraciones (cada una aumenta ≥ 1 si las capacidades son enteras); cada iteración (grafo residual + camino) cuesta O(m).
Bellman-FordO(nm)n − 1 iteraciones y en cada una se revisan todas las aristas.
Punto de articulación (fuerza bruta)O(nm)n recorridos, cada uno O(n + m) = O(m) porque G es conexo (n − 1 ≤ m).
MST sobre grafo completoO(n² log n)m = n(n−1)/2 = O(n²) y O(m log n) = O(n² log n).
Segmentación en palíndromosO(n²)n valores de OPT, cada uno con un mínimo sobre O(n) posiciones, con esP ya calculada.
