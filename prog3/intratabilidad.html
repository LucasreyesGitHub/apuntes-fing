8. Intratabilidad

Definiciones

  • Reducción Y ≤p X: se puede resolver Y con una cantidad polinomial de pasos más llamadas a un algoritmo para X. Entonces X es al menos tan difícil como Y: si X es polinomial, Y también; si Y no lo es, X tampoco. Es transitiva.
  • Problema de decisión: entrada = cadena s; salida SÍ/NO. A resuelve X si A(s) = SÍ ⇔ s ∈ X.
  • Certificador eficiente B para X: corre en tiempo polinomial con entradas (s, t), y existe un polinomio p tal que s ∈ X ⇔ existe t con |t| ≤ p(|s|) y B(s, t) = SÍ. B no resuelve el problema: solo verifica la evidencia t.
  • P: resolubles en tiempo polinomial. NP: con certificador eficiente. P ⊆ NP.
  • NP-Completo: X ∈ NP y todo Y ∈ NP cumple Y ≤p X. Resolver uno en tiempo polinomial resolvería todo NP.

Problemas típicos

ProblemaPregunta
Independent Set¿G tiene un conjunto de al menos k nodos sin aristas entre sí?
Vertex Cover¿G tiene un conjunto de a lo sumo k nodos que toca todas las aristas?
Set Cover¿Hay a lo sumo k subconjuntos de S₁..Sm cuya unión sea U?
Set Packing¿Hay al menos k subconjuntos disjuntos de a pares?
SAT¿Existe una asignación que satisface todas las cláusulas (disyunciones de literales)?
3-SATSAT con exactamente 3 literales por cláusula
  • S es Independent Set ⇔ V − S es Vertex Cover. Por eso Independent Set ≤p Vertex Cover y viceversa.
  • Vertex Cover ≤p Set Cover (U = E, un subconjunto por nodo con sus aristas incidentes).
  • Todos son NP-Completos, igual que Circuit-SAT, Clique, Hamiltonian Cycle/Path y Traveling Salesman.

Cómo probar que X es NP-Completo

  1. X ∈ NP: definir el certificado t (de tamaño polinomial), el verificador B(s, t) (tiempo polinomial) y probar que B(s, t) = SÍ ⇔ s es instancia SÍ de X.
  2. Elegir un Y NP-Completo conocido. Conviene que tenga el mismo "sentido" que X (maximizar con maximizar, minimizar con minimizar).
  3. Probar Y ≤p X: transformar una instancia arbitraria sY en una sX en tiempo polinomial y probar que sY es SÍ ⇔ sX es SÍ (las dos direcciones).

Un certificado debe tener tamaño polinomial y el verificador debe tomar tiempo polinomial. Para el "⇔" hay que mostrar ambas direcciones: si la instancia es SÍ existe un certificado que el verificador acepta, y si el verificador acepta un certificado la instancia es SÍ.

Dirección de la reducción

Error frecuente: para probar que X es NP-Completo se reduce desde un problema NP-Completo conocido Y hacia X (Y ≤p X). La instancia que se construye es de X. Hacerlo al revés no prueba nada.

Reducciones más conocidas

Cadena clásica: SAT ≤p 3-SAT ≤p Independent Set ≤p Vertex Cover ≤p Set Cover. También Independent Set ≤p Set Packing y Clique ≡p Independent Set.

3-SAT ≤ Independent Set

Construcción. Por cada cláusula (t₁ ∨ t₂ ∨ t₃) un triángulo con un nodo por literal. Se agrega una arista entre cada nodo del literal x y cada nodo del literal x̄ en cualquier triángulo. Sea k = cantidad de cláusulas. Son 3k nodos y O(k²) aristas: tiempo polinomial.

(⇒) Si una asignación satisface la fórmula, se elige un literal verdadero por cláusula. Son k nodos, uno por triángulo, y no hay arista entre dos de ellos porque x y x̄ no pueden ser verdaderos a la vez.

(⇐) Si hay un independent set de tamaño k, tiene a lo sumo un nodo por triángulo, luego exactamente uno por triángulo. Se hacen verdaderos los literales elegidos (no hay conflicto: x y x̄ están conectados); las variables restantes valen cualquier cosa. Cada cláusula tiene un literal verdadero.

Independent Set ≤ Vertex Cover

S es un independent set si y solo si V − S es un vertex cover. Se transforma (G, k) en (G, n − k): G tiene un independent set de tamaño ≥ k si y solo si tiene un vertex cover de tamaño ≤ n − k. Vale también en el otro sentido.

Vertex Cover ≤ Set Cover

U = E; para cada nodo v, Sv = aristas incidentes a v; mismo k. Elegir un vertex cover es elegir subconjuntos cuya unión cubre todas las aristas.

Independent Set ≤ Set Packing

U = E; Sv = aristas incidentes a v; mismo k. Dos nodos son adyacentes si y solo si Su y Sv comparten una arista, así que k nodos independientes dan k conjuntos disjuntos de a pares y recíprocamente.

Clique ≤ Independent Set

Se pasa al grafo complemento (se agregan las aristas que faltan y se quitan las que hay), con el mismo k. S es clique en G si y solo si es independent set en el complemento. Tiempo O(n²).

SAT ≤ 3-SAT

Una cláusula (t₁ ∨ ... ∨ tl) con l > 3 se reemplaza por (t₁ ∨ t₂ ∨ y₁), (ȳ₁ ∨ t₃ ∨ y₂), ..., (ȳl−3 ∨ tl−1 ∨ tl) con variables nuevas y. Si algún ti es verdadero se puede elegir los y para satisfacerlas todas; si todos los t son falsos, las nuevas cláusulas fuerzan una contradicción en cadena. Las cláusulas de 1 o 2 términos se completan repitiendo literales o con una variable auxiliar.

Clique ≤ Subgrafo Isomorfo (examen 2024)

Dada (G, k) se construye el grafo completo Kk en O(k²) y se pregunta si Kk es isomorfo a un subgrafo de G. Si G tiene un clique de tamaño k, ese subgrafo es completo, o sea isomorfo a Kk. Recíprocamente, un subgrafo isomorfo a Kk es un clique de tamaño k.

SAT ≤ Al Menos k (examen 2025)

Un evento por variable xi. Por cada cláusula, un apostador que apuesta Gi por cada término xi y Pj por cada término x̄j. Se agregan dos apostadores más, (Gn) y (Pn), y se toma k = (cantidad de cláusulas) + 1.

Exactamente uno de los dos apostadores extra acierta siempre. Por eso, para llegar a k aciertos, los apostadores de las cláusulas deben acertar todos. Sin esos dos extra, una asignación que satisface k′ − 1 de las k′ cláusulas convertiría una instancia NO de SAT en una instancia SÍ del problema nuevo.

Hamiltonian Cycle ≤ Traveling Salesman

Dado G con n nodos, se arma el grafo completo con distancia 1 entre nodos adyacentes en G y 2 en otro caso, y cota n. Hay un recorrido de largo ≤ n que pasa por todos los nodos y vuelve si y solo si G tiene un ciclo hamiltoniano (solo se pueden usar aristas de G).
