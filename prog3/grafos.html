3. Grafos

  • Grafo G = (V, E). No dirigido: relación simétrica. Dirigido: asimétrica.
  • Camino simple: sin vértices repetidos. Ciclo: camino con k > 2, primeros k − 1 nodos distintos y v₁ = vk.
  • Conexo (fuertemente conexo en dirigidos): todos alcanzables entre sí.
  • Distancia: mínimo número de aristas entre u y v (∞ si no hay camino).
  • Árbol: conexo, sin ciclos, con n − 1 aristas. Quitar cualquier arista lo desconecta.

En no dirigidos, la suma de los largos de las listas es 2m = O(m).

BFS

Desde s (capa L₀) explora por capas. Lj contiene los nodos a distancia j de s. Si (x, y) es arista de G con x ∈ Li e y ∈ Lj, entonces |i − j| ≤ 1. El resultado es la componente conexa de s.

BFS(G, s):
  Descubierto[s] = true, el resto false; L[0] = {s}; i = 0; T = ∅
  while L[i] no vacía:
      L[i+1] = ∅
      for u in L[i]:
          for (u, v) incidente a u:
              if !Descubierto[v]: Descubierto[v] = true; T += (u,v); L[i+1] += v
      i++

DFS

Explora en profundidad recursivamente (o con una pila). Visita los mismos nodos que BFS en otro orden, y el árbol resultante es muy distinto.

DFS(u):
  Explorado[u] = true
  for (u, v) incidente a u:
      if !Explorado[v]: DFS(v)

Ambos corren en O(n + m): cada nodo entra una sola vez a la cola/pila y cada arista se ve desde sus dos extremos. BFS usa cola; DFS iterativo usa pila y un arreglo Padre.

Aplicaciones

  • Bipartito: V = V₁ ∪ V₂ disjuntos, con todas las aristas entre V₁ y V₂. Un grafo es bipartito si y solo si no tiene ciclos de largo impar. Con BFS: si hay una arista entre dos nodos de la misma capa, hay un ciclo impar y no es bipartito.
  • DAG: dirigido sin ciclos. Admite un orden topológico: ninguna arista apunta hacia atrás.
  • Detectar ciclos en dirigidos con DFS: hay ciclo si, explorando los vecinos de x, aparece un nodo que está en la pila de recursión actual (no basta con que esté explorado: eso también ocurre en aristas cruzadas o hacia adelante sin que haya ciclo).
  • Orden topológico (algoritmo de Kahn): calcular el grado de entrada de cada nodo; poner en una lista L los de grado 0. Mientras L no esté vacía, sacar un nodo, agregarlo al orden y restarle 1 al grado de entrada de sus vecinos; los que llegan a 0 entran en L.

Pseudocódigo: DFS iterativo

DFS-Iterativo(G, s):
  S = pila con (s, nulo);  Explorado[*] = false;  T = ∅
  mientras S no vacía:
      (u, padre) = pop(S)
      si !Explorado[u]:
          Explorado[u] = true
          si padre ≠ nulo: T = T ∪ {(padre, u)}
          para cada arista (u, v):  push(S, (v, u))
  devolver T

Guardar el padre dentro de la pila evita que un Padre[v] global se pise si v se apila varias veces.

Pseudocódigo: detectar ciclos en un grafo dirigido

Hay-Ciclo(G):
  estado[v] = blanco para todo v          // blanco: sin visitar, gris: en la recursión, negro: terminado
  para cada v blanco: DFS(v)

DFS(u):
  estado[u] = gris
  para cada arista (u, v):
      si estado[v] = gris:   hay ciclo (v es ancestro de u)
      si estado[v] = blanco: padre[v] = u;  DFS(v)
  estado[u] = negro

Pseudocódigo: orden topológico

Orden-Topologico(G):
  para cada v: grado[v] = cantidad de aristas entrantes a v
  L = cola con todos los v de grado 0;  OT = []
  mientras L no vacía:
      u = sacar(L);  OT.agregar(u)
      para cada arista (u, v):
          grado[v]--                       // borrado lógico de (u, v)
          si grado[v] = 0: L.agregar(v)
  si |OT| < n: el grafo tiene un ciclo (no es DAG)
  devolver OT

Cada nodo entra una vez a L y cada arista se descuenta una vez: O(n + m).

Ejemplo de examen: punto de articulación en O(nm)

Punto-Articulacion(G):                       // G conexo, n > 2
  para cada v ∈ V:
      x = cualquier nodo distinto de v
      BFS desde x sin pasar por v;  cont = cantidad de nodos alcanzados
      si cont < n − 1: devolver v            // G − {v} es disconexo
  informar que G no tiene puntos de articulación

Tiempo: n recorridos de O(n + m) = O(m) cada uno, porque G es conexo (n − 1 ≤ m). Total O(nm).

Ejemplo de examen: bipartición única con DFS

Distribuir(G):
  color[v] = nulo para todo v;  componentes = 0
  para cada v con color[v] = nulo:  componentes++;  DFS(v, A)
  informar "posible";  única ⇔ componentes = 1

DFS(v, c):
  color[v] = c
  para cada w adyacente a v:
      si color[w] = nulo:  DFS(w, opuesto(c))
      sino si color[w] = color[v]:  informar "imposible"; terminar

La distribución es única si y solo si el grafo es conexo: cada componente conexa tiene una única bipartición, pero con varias componentes se pueden combinar de dos maneras distintas (A₁ ∪ A₂, B₁ ∪ B₂) o (A₁ ∪ B₂, B₁ ∪ A₂).
