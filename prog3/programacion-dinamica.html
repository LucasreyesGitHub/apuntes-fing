6. Programación dinámica

Se descompone el problema en subproblemas que se solapan (a diferencia de divide y vencerás) y se construye la solución de menor a mayor, guardando resultados. Requiere:

  1. Solo una cantidad polinomial de subproblemas.
  2. La solución original se obtiene fácil a partir de las de los subproblemas.
  3. Un orden natural de más chico a más grande, con una recurrencia fácil de evaluar.

Memoización: guardar cada resultado en una tabla para calcularlo una sola vez (consulta en O(1)). Versión iterativa: llenar la tabla de menor a mayor; luego se recorre hacia atrás para reconstruir la solución.

Intervalos ponderados

Cada trabajo (si, fi, wi). Maximizar la ganancia sin solapar (el greedy de la sección 4 no sirve acá). Ordenar por fin; p(j) = mayor i < j compatible con j.

OPT(0) = 0
OPT(j) = max{ w_j + OPT(p(j)),  OPT(j-1) }      // j entra o no entra

Solución: i = n; mientras i > 0:
    si OPT[i] = w_i + OPT[p(i)]: agregar i; i = p(i)   sino: i = i - 1

Mínimos cuadrados segmentados

Puntos p₁..pn con x₁ < ... < xn. Error de una recta y = ax + b: Σ(yi − axi − b)². Penalización = C × (cantidad de segmentos) + suma de errores. Es una recurrencia multi-way choice: el último segmento empieza en algún i entre 1 y j.

OPT(0) = 0
OPT(j) = min_{1 ≤ i ≤ j} { e_{i,j} + C + OPT(i-1) }

Calcular todos los ei,j cuesta O(n³) (n² pares, O(n) cada uno). El resto es O(n²).

Mochila y Subset Sum

n ítems con peso wi y valor vi, capacidad W. Maximizar el valor con peso total ≤ W. Subset Sum es el caso en que valor = peso. Hace falta una variable extra: la capacidad restante.

OPT(0, w) = 0   y   OPT(i, 0) = 0
si w_i > w:   OPT(i, w) = OPT(i-1, w)
sino:        OPT(i, w) = max{ v_i + OPT(i-1, w - w_i),  OPT(i-1, w) }

Tabla de (n+1) × (W+1): O(nW). Es pseudo-polinomial: polinomial en n y en el valor de W, pero no en el tamaño de la entrada (W se escribe con log W bits). Impracticable si W es enorme.

Estructura secundaria de ARN

Cadena b₁..bn sobre {A, C, G, U}. Emparejamiento S de pares (i, j) tal que: (1) j − i > 4; (2) los pares son A-U o C-G; (3) cada base está en a lo sumo un par; (4) sin cruces: no existen (i, j), (k, l) con i < k < j < l. Se usan subproblemas {i..j}.

OPT(i, j) = 0                si j - i ≤ 4
OPT(i, j) = max{ OPT(i, j-1),
                 max_t { 1 + OPT(i, t-1) + OPT(t+1, j-1) } }   // t empareja con j, i ≤ t < j - 4

Se llena por longitud creciente k = j − i. Tiempo O(n³).

Alineación de secuencias

X = x₁..xm, Y = y₁..yn. Un alineamiento es un emparejamiento sin cruces. Costo: δ por cada posición sin emparejar, αp,q por cada par discordante (αp,p = 0). En un alineamiento óptimo, ocurre al menos una: (m, n) ∈ M, xm sin emparejar, o yn sin emparejar.

OPT(i, 0) = δ·i      OPT(0, j) = δ·j
OPT(i, j) = min{ α(x_i, y_j) + OPT(i-1, j-1),  δ + OPT(i-1, j),  δ + OPT(i, j-1) }

Pseudocódigo: mochila (llenado y reconstrucción)

Mochila(n, W, w[], v[]):
  OPT[0][x] = 0  y  OPT[i][0] = 0  para todo i, x
  para i = 1..n:
      para x = 1..W:
          si w[i] > x: OPT[i][x] = OPT[i-1][x]
          sino:        OPT[i][x] = max( OPT[i-1][x],  v[i] + OPT[i-1][x − w[i]] )
  devolver OPT[n][W]

Reconstruir(OPT, n, W):
  S = ∅;  x = W
  para i = n hasta 1:
      si w[i] ≤ x y OPT[i][x] = v[i] + OPT[i-1][x − w[i]]:
          S = S ∪ {i};  x = x − w[i]
  devolver S

Pseudocódigo: mínimos cuadrados segmentados

MCS(n, C):
  para cada par i ≤ j: calcular e[i][j]                 // O(n³) en total
  OPT[0] = 0
  para j = 1..n:
      OPT[j] = min sobre 1 ≤ i ≤ j de ( e[i][j] + C + OPT[i-1] )

Reconstruir(j):
  si j = 0: terminar
  i* = el i que minimiza e[i][j] + C + OPT[i-1]
  imprimir el segmento p[i*..j];  Reconstruir(i* − 1)

Pseudocódigo: estructura secundaria de ARN

ARN(b[1..n]):
  OPT[i][j] = 0 si j − i ≤ 4 o i > j
  para k = 5..n−1:
      para i = 1..n−k:
          j = i + k
          OPT[i][j] = OPT[i][j-1]                       // j sin pareja
          para t = i..j−5:                              // j se empareja con t
              si (b[t], b[j]) es A-U, U-A, C-G o G-C:
                  OPT[i][j] = max( OPT[i][j],  1 + OPT[i][t-1] + OPT[t+1][j-1] )
  devolver OPT[1][n]                                    // O(n³): n² celdas, O(n) cada una

Pseudocódigo: alineación de secuencias

Alineacion(X[1..m], Y[1..n], δ, α):
  OPT[i][0] = i·δ  y  OPT[0][j] = j·δ
  para j = 1..n:
      para i = 1..m:
          OPT[i][j] = min( α(x_i, y_j) + OPT[i-1][j-1],
                           δ + OPT[i-1][j],
                           δ + OPT[i][j-1] )
  devolver OPT[m][n]                                    // O(mn) en tiempo y espacio

Reconstruir desde (i, j) = (m, n), mientras (i, j) ≠ (0, 0):
  si OPT[i][j] = α(x_i, y_j) + OPT[i-1][j-1]: emparejar x_i con y_j;  i--;  j--
  sino si OPT[i][j] = δ + OPT[i-1][j]:         x_i queda sin pareja;  i--
  sino:                                         y_j queda sin pareja;  j--
